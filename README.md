# Automower BLE Plus

A Home Assistant integration for Husqvarna Automower robotic lawn mowers that support Automower Connect over Bluetooth Low Energy. Use a Bluetooth adapter connected to Home Assistant or an ESPHome proxy with active connections enabled.

## Highlights

- **v0.43** · Request an Automower Connect account pairing code over Bluetooth on supported mowers.
- **v0.42** · Remove paired Automower Connect accounts over Bluetooth on compatible mowers with a Connect module.
- **v0.41** · Edit the mower's local date and time over Bluetooth, including on the known Automower 420 profile.
- **v0.40** · View estimated distance travelled and receive live Bluetooth statistics on compatible firmware, including the known 420 profile.
- **v0.39** · Choose the headlight theme on supported mowers.
- **v0.38** · View or adjust the global cutting height in millimetres on compatible firmware.
- **v0.37** · Select random, parallel, checkerboard or triangle mowing for compatible work areas.
- **v0.36** · Change mowing settings for compatible work areas directly in **Automower Maps**.
- **v0.35** · See why the mower is waiting and receive updates when its next start time changes.
- **v0.34** · See TargetHeight progress, the current cutting height and GPS-assisted navigation status where reported by the mower.
- **v0.33** · Edit weekly work area schedules from **Automower Maps** on compatible models.
- **v0.32** · Add an all-day schedule when you create a compatible work area in **Automower Maps**.
- **v0.31** · View read-only AIM maps on six older firmware builds, including versions for the 405X and 415X.
- **v0.30** · See release highlights in Marketplace and during initial setup.
- **v0.29** · View BLE maps and draw or edit zones and paths in **Automower Maps** on compatible models.
- **v0.27–0.28** · Create and edit AIM stay-out zones. Link AIM work areas to mowing missions for scheduling.
- **v0.23–0.26** · Change the PIN, check and regenerate the AIM map, and set up the EPOS boundary and origin on supported firmware.
- **Automower 420** · The known firmware profile supports boundary and guide wire settings, weekly scheduling, PIN management and controls for the Automower Connect module when fitted.

[View the changelog](https://github.com/olerida/automower-ble-plus/blob/main/CHANGELOG.md)

## Install from Marketplace

1. In Home Assistant 2026.11.0 or later, open **Settings → Marketplace → Add from link**. Add `olerida/automower-ble-plus` as an integration and install **Automower BLE Plus**. [Open in Marketplace](https://my.home-assistant.io/redirect/hacs_repository/?owner=olerida&repository=automower-ble-plus&category=integration)
2. If the same mower is configured in **Husqvarna Automower BLE**, disable that entry so only one integration manages the connection.
3. In **Settings → Devices & services**, configure the discovered mower or add **Automower BLE Plus** with its Bluetooth address. Put the mower in pairing mode and enter its PIN if your model requires it.

## Features

View mower status, start, pause, park, resume the schedule and send timed commands. Battery, statistics, ECO mode, Weather Timer, frost protection, cutting height, headlights, installation and other settings appear according to the mower's firmware. Detection begins after the first connection.

Compatible mowers also expose spiral cutting and its intensity, along with any theft alarm sensors the mower reports. Set the operator PIN when adding the integration to edit theft protection settings.

- **Headlight theme** shows the lighting modes defined for the mower's firmware when the mower confirms that headlights are available. [Husqvarna Automower 550 EPOS manual](https://www-static-nw.husqvarna.com/hbd/tdrdownload/v2/pub000091766/doc000227307/OM/vNo9syZrADzn-OFbfZTVWYbWTzk)
- **Estimated distance travelled** uses operating time and the mower model's nominal speed. Operating time, charging cycles, collisions and blade usage can also update when the mower sends a Bluetooth notification. [Husqvarna statistics guide](https://www.husqvarna.com/uk/support/what-statistics-does-automower-connect-show-and-how-often-is-it-updated-ka-01474/)
- On a mower with an Automower Connect module, **Configure → Remove paired Automower Connect accounts** requests removal of all account pairings. Enter the current PIN and confirm that the accounts will lose remote access. [Husqvarna pairing removal guide](https://www.husqvarna.com/ca-en/support/how-to-remove-pairings-from-your-automower-robotic-lawn-mower-ka-01296/)
- **Configure → Get Automower Connect pairing code** asks an enabled module for a fresh code. Enter the mower's PIN in Home Assistant, then use the displayed code when adding the mower in the Automower Connect app. [Husqvarna pairing instructions](https://www.husqvarna.com/us/discover/how-tos-and-guides/automower-faq/)

- **TargetHeight in progress** shows whether the mower is gradually lowering the cutting height. It includes the reported duration when available. On models with a current-height reading, Home Assistant shows the actual height as a level or percentage. [Husqvarna TargetHeight guide](https://www.husqvarna.com/uk/support/automower-support-guide-by-season-ka-70343/)
- **Global cutting height** shows the mower-wide target in millimetres when the firmware reports it. If the firmware supports native writes, the control uses the current range reported by the mower. The existing **Cutting height** level remains available on models that provide it, including the known 420 profile. [Husqvarna cutting height guide](https://www.husqvarna.com/uk/support/automower-support-guide-by-season-ka-70343/)
- **GPS-assisted navigation status** shows whether there is no signal, the mower is initializing, or the GPS map is in use. It appears when the mower confirms support for GPS-assisted navigation and returns a valid state. [Husqvarna navigation guide](https://www.husqvarna.com/uk/support/automower-robotic-lawn-mower-navigation-accuracy-ka-01692/)

- **Weekly mowing schedule** appears in **Calendar**. Create daily or weekly recurring intervals with no end date. To edit or delete an interval, open its next occurrence and choose **This and following events**. New intervals in Calendar apply to the main area. Editing an interval preserves its work area. Home Assistant rereads the schedule when the mower sends a Bluetooth notification. The calendar and next start time use the mower's time zone when configured. [Home Assistant Calendar](https://www.home-assistant.io/integrations/calendar/)
- `get_schedule` reads the weekly intervals and their limits. `replace_schedule` writes a new schedule and reads it back. Each interval uses `start` (local time), `duration_minutes`, `weekdays` (`mon` through `sun`) and, where applicable, `mission_id`.
- **Mower local date** and **Mower local time of day** edit the clock used by the mower's schedule. If the mower supports automatic clock synchronization, switch it off before setting the clock manually. **Synchronize mower clock** sets the current time using the mower's configured time zone or Home Assistant's time zone. Automatic synchronization corrects clock drift of more than a minute and seasonal time changes when the mower has a configured time zone. [Automower 420 operator's manual](https://www.husqvarna.com/hbd/tdrdownload/v2/pub000091122/doc000217817/OM/pQKSkezea5LfPWtSyTgai2IrTjM?httproute=True)
- **Name stored on the mower** lets you read and change the name saved on the device. The device registry shows the serial number when the mower reports it over Bluetooth. [Home Assistant text entities](https://contributors.home-assistant.io/core/entities/text/)
- **Reset user settings** appears under **Settings → Devices & services → Automower BLE Plus → Configure** when the integration identifies compatible firmware, including the known 420 profile. The form identifies the mower and asks you to confirm the reset, which can erase schedules and map objects. Home Assistant reconnects and reads the settings. [Husqvarna reset guide](https://www.husqvarna.com/us/support/articles/how-to-restart-or-reset-your-automower-robotic-lawn-mower-ka-01096/)
- **Change PIN** appears under **Configure** when the firmware is identified and the mower confirms the operator session. Enter the current PIN and enter the new PIN twice. Home Assistant saves the new PIN when the mower confirms the change. If the operation is interrupted, check which PIN the mower accepts and complete reauthentication in Home Assistant. [Husqvarna PIN guide](https://www.husqvarna.com/uk/support/husqvarna-self-service/how-to-change-or-recover-the-automower-pin-code-ka-70291/)
- On models that report Wi-Fi support, open **Configure → Wi-Fi networks** to scan from the mower, join a network or manage saved networks. The mower saves the credentials and confirms the connection over Bluetooth. Its device page also shows a Wi-Fi switch, connection status and signal strength.
- When the mower reports an **Automower Connect** module, Home Assistant shows its status, SIM errors and signal strength as a percentage. On a 420, configure the mower PIN to enable or disable the module from the device page. Firmware that accepts the change without an extra PIN exposes the switch when the module is detected.
- **Schedule override** shows whether a mowing or parking override is active. Its attributes include the requested duration and the work area ID when the firmware reports it.
- **Mowing restriction** shows why the mower is waiting, such as the weekly schedule, a parking override, the daily operating limit or Frost Guard. It updates when the mower sends Planner notifications. The **Restriction reason** sensor retains its numeric code for existing automations. [Husqvarna schedule troubleshooting](https://www.husqvarna.com/uk/support/automower-robotic-lawn-mower-not-following-scheduled-cutting-times-ka-01506/)
- On models with GPS, enable **Mower position** on the device page to show the mower on the Home Assistant map, with BLE updates every 30 seconds. The `get_position` action reads GPS and, on compatible firmware, installation coordinates, geographic origin, heading and accuracy.
- When a mower provides maps over BLE, its device page shows the available **Installation map**, **Generated lawn map** or **Zone map**. You can add these images to a Home Assistant dashboard. Green marks work areas, red marks stay-out zones, blue marks transport paths and yellow marks the charging station. `get_zone_map` returns zone map geometry. [Home Assistant image entities](https://contributors.home-assistant.io/core/entities/image/)
- **Automower Maps** appears in the sidebar when a mower has compatible maps. Select a map and an item to edit it. Add points on the map, drag them or enter coordinates. If the mower reports its local position, you can capture a point directly from the mower. The panel shows the actions supported by each map and checks the map revision before saving.
- On AIM models, the device page shows map status, progress and the last update as reported by the firmware. With a completed map and compatible firmware, **Configure → Regenerate AIM map** starts a new mapping session over Bluetooth. The mower collects data when it next mows on its schedule. [Husqvarna AIM map update guide](https://us-support.husqvarna.com/en/automower/KA-70070)
- **Active fault** shows common faults in English or Spanish. **Acknowledge fault** is available when the mower permits the current fault to be acknowledged. `get_message_history` returns a page of history with raw codes, severity and a message ID when available.
- If the firmware sends new messages over Bluetooth, you can use the **Mower messages** event entity in automations. Each event includes the code and severity. [Home Assistant event entities](https://contributors.home-assistant.io/core/entities/event/)
- `mow_secondary_area` starts secondary area mode. If you omit `minutes`, the mower cuts until the battery is low.
- `get_work_areas` returns area names and IDs on compatible models. Pass `mission_id` to `mow_for` to mow that area or to `update_work_area` to change its name or enabled state.
- `get_work_area_mowing` reads an area's pattern, direction, perimeter mowing and cutting height. On compatible models it also includes vision assistance, obstacle detection and daylight-only mowing. `set_work_area_mowing` changes a setting listed in `editable`. Use the unit reported by the read action for height, either a percentage or a level from 1 to 9.
- Select a work area in **Automower Maps** and open **Mowing settings** to edit the controls reported by the mower. Select one setting and save its new value. Available controls can change after switching the mowing pattern. The actions `get_map_work_area_mowing` and `set_map_work_area_mowing` use the map revision and linked mission to confirm the selected area. [Husqvarna work area settings](https://www.husqvarna.com/us/discover/wireless-automower-faqs/)
- On compatible firmware, the mowing editor offers **Random**, **Parallel**, **Checkerboard** and **Triangle**. Automations can set `mowing_pattern_preset` to `random`, `parallel`, `checkerboard` or `triangle` when that field is listed in `editable`. [Husqvarna systematic mowing guide](https://www.husqvarna.com/uk/support/what-is-systematic-mowing-ka-70248/)
- `get_work_area_status` reads progress for the current or selected area. `reset_work_area_progress` resets stored progress. On compatible firmware, `set_work_area_mowing` also changes priority.
- `create_work_area` links a mowing mission to an existing work area polygon. Use the polygon `id` and the checksum returned by `get_map`. Before deleting a mission with `delete_work_area`, remove its scheduled intervals and provide its ID and exact name.
- **Active installation** appears when the mower reports multiple installations. `get_installations` returns the profiles and the active ID. Actions support activation, renaming, copying and, on supported firmware, creating an empty installation. To remove an inactive profile, provide its ID and exact name.
- `get_map` reads the active map's SVG and checksum on compatible firmware. `replace_map` uploads an SVG in Automower format. Pass the `checksum` returned by `get_map` as `expected_checksum` to protect the revision you are editing.
- `get_map_features` returns active, generated or zone map features with an ID, name, type and local coordinates in millimetres. To move the vertices of an editable feature on the active map, call `edit_map_geometry` with its ID, the list of `x_mm` and `y_mm` points, the checksum and, when present, the `installation_id` as `expected_installation_id`. Home Assistant validates the coordinates and revision before saving.
- `set_map_feature_settings` changes a zone or path name, enabled state or width on the active map. `get_map_features` reports supported fields in `editable_settings` and the model's width limits in `width_limits_mm`. Use the same ID, checksum and installation ID as for geometry edits. Use `update_work_area` for mowing mission settings. [Husqvarna guide to EPOS zones and paths](https://www.husqvarna.com/uk/support/set-up-and-manage-work-areas-stay-out-zones-and-transport-paths-with-epos-wire-free-technology-ka-70385/)
- `create_map_feature` adds a work area, stay-out zone, transport path or point-of-interest path. Supply the name, map points, map revision and the width in millimetres for a path. Creating a work area also creates its mowing mission. `delete_map_feature` removes a feature by ID and revision. Before deleting a work area with a linked mission, remove its scheduled intervals.
- On firmware that supports work area schedules, select **Allow mowing all day, every day** when creating an area in **Automower Maps**, or pass `schedule_full_day: true` to `create_map_feature`. Home Assistant adds a recurring 24-hour interval for each day to the existing schedule. If the mower confirms the area but Home Assistant cannot confirm the schedule, the action returns `schedule_confirmed: false` and the panel prompts you to check Calendar.
- To edit an existing work area's intervals, select it in **Automower Maps** and choose **Schedule**. Times use the mower's time zone and intervals can cross midnight. `get_work_area_schedule` returns the intervals and their revision. Pass the schedule revision and map revision to `replace_work_area_schedule`. An empty list clears that area's schedule.
- On compatible AIM firmware, `get_map_features` with `map_type: zones` returns the zone map revision and editable features. When `can_create` is true, use the same actions with `map_type: zones` to create, reshape, rename, enable or delete a stay-out zone. Pass the zone map's `checksum` and `installation_id` as the expected revision and installation. [Husqvarna AIM stay-out zones guide](https://us-support.husqvarna.com/en/automower/KA-01699)
- If `creatable_types` includes `work_area`, you can also create, reshape and delete AIM work areas. On creation, Home Assistant links the mowing mission and returns its `mission_id` for schedules and mowing settings. Remove the mission's scheduled intervals before deleting the area. [Husqvarna AIM work areas guide](https://www.husqvarna.com/us/support/creating-and-managing-work-areas-with-aim-technology-ka-01698/)
- **Park at point of interest** appears when the firmware supports the command and the active map has an enabled point-of-interest path. Press the button to send the mower to the configured destination.
- `get_geofence` reads GeoFence status. The switch, radius, sensitivity and button to centre it on the current position appear according to the model and firmware. Controls that require the mower PIN appear only if it is configured in Home Assistant.
- **Pair charging station** creates a new loop signal when the mower is docked and waits for confirmation. On firmware with boundary wire diagnostics, `get_loop_signals` reads only installed loops and identifies which sensor took each reading.
- In wired installations, you can adjust the corridor width for the boundary wire and each supported guide wire. **FlexiFence detection** appears on mowers that support the accessory. [Corridor width](https://www.husqvarna.com/uk/support/articles/how-to-adjust-the-corridor-width-in-a-boundary-wire-automower-installation-ka-01717/) · [FlexiFence](https://www.husqvarna.com/uk/support/articles/install-and-use-automower-flexi-fence-in-boundary-wire-installations-ka-70418/)
- **Test starting point** and **Test return** test the wire routes the mower supports. For departure, place the mower in the station. For return, place it outside the station, about three metres from the wire and facing it. On a 420, press **STOP** on the mower, prepare the test in Home Assistant and press **START** on the mower to run it. You can stop the test and save the last measured distance as a starting point.
- On EPOS models, sensors report the RTK solution, correction signal quality and charging station installation state according to the firmware. **EPOS support by wire** appears when the mower can supplement satellite positioning with a physical wire.
- Compatible EPOS models show the perimeter type, correction source and service status. They also report whether the origin is registered and valid when the mower provides that information. If the mower supports docking by guide wire, **EPOS docking method** lets you select it while the mower is docked. [EPOS docking by wire](https://www.husqvarna.com/us/support/epos-dock-by-wire-for-remote-charging-station-placement-ka-70360/)
- If the mower supports a local EPOS reference station, press **Find EPOS reference stations** on the Home Assistant device page. The scan lasts one minute. Select the station ID under **EPOS reference station**. The mower registers the station's current position as its installed position. If the station has moved, follow Husqvarna's reinstallation procedure. [EPOS reference station reinstallation](https://www.husqvarna.com/uk/support/when-and-how-to-reinstall-epos-or-the-reference-station-in-an-automower-wire-free-installation-ka-70363/)
- On compatible models, place the mower in the charging station and press **Set EPOS docking point**. The mower pauses before the manoeuvre and the EPOS sensors show the result. If you moved the station, check that the transport paths connect to the new point on the map. [Husqvarna charging station reinstallation guide](https://www.husqvarna.com/uk/support/when-and-how-to-reinstall-the-automower-charging-station-in-an-epos-wire-free-installation-ka-70415/)
- In a compatible empty installation profile, **Configure → Set up Husqvarna Cloud EPOS origin** selects the service and registers the current position as the origin when the mower is ready. Keep the mower under open sky, within Bluetooth range and connected to the internet for corrections. To use this source in a new installation, first create and activate its own profile. [Husqvarna EPOS installation and positioning sources](https://www.husqvarna.com/uk/support/when-and-how-to-reinstall-epos-or-the-reference-station-in-an-automower-wire-free-installation-ka-70363/)
- On models that support both systems, **Configure → Change perimeter type** switches between a boundary wire and a virtual EPOS perimeter. The change may erase perimeters, work areas, stay-out zones and schedules. The form asks for confirmation before sending the change and Home Assistant rereads the settings afterwards. [Husqvarna perimeter change guide](https://www.husqvarna.com/uk/support/how-to-switch-from-epos-to-boundary-wire-installation-on-automower-ka-70109/)
- On compatible models, **Undock with appDrive** starts the manoeuvre when the mower is docked, paused and reports that it can undock. Enable remote control on the mower if your model requests it. Home Assistant shows the result and lets you request a stop with **Stop appDrive**. [Husqvarna appDrive guide](https://www.husqvarna.com/uk/support/set-up-and-manage-work-areas-stay-out-zones-and-transport-paths-with-epos-wire-free-technology-ka-70385/)
- **Enter charging station with appDrive** is available when the mower reports that it can dock. Home Assistant shows the result after the mower docks or begins charging. **Stop appDrive** requests a stop during the manoeuvre.
- **Automower appDrive** appears in the sidebar when a compatible mower is present. Select the mower, undock it and pause it. Hold and drag the joystick or use the arrow keys to drive. Releasing the control sends a zero-speed command. [Home Assistant custom panels](https://contributors.home-assistant.io/frontend/custom-ui/panel/)
- On models with FOTA support, Home Assistant shows mower or charging station firmware and lets you check for and install an update prepared by the device. The command goes over Bluetooth. The device downloads its firmware over the connection supported by its model. [Husqvarna firmware update guide](https://www.husqvarna.com/uk/support/how-to-update-your-automower-firmware-ka-01099/)
- When the mower provides a valid position, you can enable its device tracker in Home Assistant.

The Automower 420 is the reference model. Automated tests reproduce pairing and capability detection with a simulated mower. The [BLE protocol inventory](docs/ble.md) documents coverage and features awaiting verification on physical hardware.

This community integration uses AutoMower-BLE for pairing and Bluetooth channel setup. [AutoMower-BLE project](https://github.com/alistair23/AutoMower-BLE)

Build the distribution ZIP with `python3 tools/build_hacs_release.py`. When a version tag matches the integration manifest, GitHub Actions publishes the archive used by Marketplace and HACS after tests and Hassfest pass.
